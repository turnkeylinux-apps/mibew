# Mibew 19.0 testing

## Source decision

Debian 13 Trixie does not package Mibew. The appliance installs Mibew 3.6.0
from the official complete release archive and verifies the SHA-256 digest
published on Mibew's download page. PHP 8.4, MariaDB, Apache and PHP extensions
come from signed Trixie repositories.

The upstream repository is active and unarchived, the official site continues
to publish project updates, and Mibew documents a supervised update process.
Updates replace application files from a reviewed release and then use the
built-in ``/update/`` database migration.

Mibew 3.6.0 represents an ungrouped thread as numeric zero in application
code, although its schema declares a nullable foreign key. The appliance maps
that value to SQL `NULL` when persisting a thread so current MariaDB can enforce
the declared relationship and ordinary visitor requests continue to work.

## Acceptance command

```sh
/sandboxed-git/turnkey/tools/test-v19-appliance mibew \
    --source /home/agent/.local/worktrees/turnkey-apps/mibew/wish-mibew-v19-trixie
```

The command builds the Trixie root filesystem, imports it into Docker, boots
the normal systemd and firstboot path, then runs `tests/v19.sh`.

## README crosswalk

| README contract | Focused check | Required result |
| --- | --- | --- |
| Mibew provides website visitor support | Submit a visitor support request through Mibew's real client API, then read it through the authenticated operator history | The visitor, support message and persisted thread are visible to the administrator |
| Firstboot sets the administrator password | Log in through the CSRF-protected operator form with the preseeded password | The operator dashboard loads and the password uses Mibew's supported hash |
| Mibew is served over TLS | Validate Apache and request application pages over HTTPS | Apache is active and Mibew pages load over TLS |
| Mibew 3.6.0 comes from maintained upstream source | Read `VERSION.txt` and query the official latest release endpoint | The runtime and release channel report 3.6.0 |
| Adminer, Webmin and local mail support are available | Query MariaDB, inspect Webmin modules and HTTPS, and check Postfix's loopback listener | The database works, Webmin answers and local SMTP listens |
| Debian packages receive Trixie updates | Inspect installed packages and active APT suites | Required PHP and MariaDB packages are installed and no Bookworm source remains |
| SSH, backup and other base services are inherited from Core | Reuse the passing Core 19 baseline | Core 19 acceptance remains the inherited evidence |

## Cheap platform preflight

`tests/v19-preflight.sh` runs in a disposable Trixie container. It installs the
required Debian packages, verifies the official release digest, runs Mibew's
real web installer against MariaDB and checks the administrator and schema.

## Deferred issues

The focused test uses Mibew's offline support-request path rather than holding
a two-browser live chat session. It exercises the same application, visitor
request processor, message persistence and authenticated operator history.
External mail delivery and multi-operator concurrency remain environment-level
follow-up tests.
